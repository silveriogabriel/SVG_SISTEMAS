# 🚀 SVG Sistemas — Central Oficial de Atualizações

**Enquanto uns vendem, outros evoluem!**

O SVG Sistemas é uma solução de gestão comercial desenvolvida para modernizar estabelecimentos, simplificar operações e proporcionar maior controle, segurança e eficiência aos empresários.

## 💻 Principais funcionalidades

- Frente de caixa (PDV).
- Controle de estoque e produtos.
- Gerenciamento de mesas e comandas.
- Gestão de clientes e fornecedores.
- Contas a receber e controle de fiado.
- Gestão financeira e despesas.
- Emissão de orçamentos em PDF.
- Relatórios de vendas e lucratividade.
- Impressão de recibos e cupons.
- Gerenciamento de usuários e permissões.
- Controle de licenciamento.
- Funcionamento offline com banco de dados local.

## 🔄 Central de atualizações

Este repositório é destinado exclusivamente à distribuição oficial de atualizações do SVG Sistemas, incluindo:

- Novas funcionalidades.
- Correções de erros.
- Melhorias de desempenho.
- Atualizações de segurança.
- Melhorias de interface e usabilidade.
- Novas versões dos instaladores.

O mecanismo de atualização automática tem como objetivo manter os clientes sempre atualizados, preservando seus dados, configurações e licenças.

## 🛠️ Tecnologias utilizadas

- .NET 8
- Windows Forms
- Firebird Database
- Inno Setup
- GitHub Releases
